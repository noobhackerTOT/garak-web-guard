GETTING STARTED

从登录到报告.

一次配置，重复检测。

  1. 打开独立浏览器并登录

    填写聊天网页地址，点击“打开浏览器并登录”。在新窗口手动完成登录，进入可聊天的页面。

  2. 配置网页元素

    点击“定位 AI 对话”，从候选列表选择对话区；也可以点击“点选”，切换到浏览器选择对应元素。回答区域应覆盖整个回答，并匹配后续新回答。点选结果如果包含固定 nth-of-type，建议改为重复回答元素的通用 class 或 data 属性。点选 iframe 内部元素时会自动填写所属 iframe。

  3. 验证连接

    “检查选择器”验证元素是否存在。“连接测试”只发送“请只回复：连接成功”，不执行安全探针。确认返回完整的新回答后再开始检测。流式页面建议配置“生成中按钮 / 状态选择器”。

  4. 选择探针并检测

    建议先选 1–5 个问题。每组数量是上限，部分探针自身问题更少。建议配置新对话按钮，并启用每题新对话。连续对话的前文会影响后续测试，报告会记录此设置。

  5. 复核风险与导出

    命中记录显示问题、回答和 garak 检测器分值。检测器分值不是漏洞概率；关键词命中可能误报。HTML 报告可独立打开，JSON 可用于后续分析，JSONL 保留 garak 原始数据。训练文本复现探针不检测系统提示词或私人账号数据泄漏。

本地模拟网页用于验证操作流程和检测链路。模拟结果不代表任何真实 AI 产品的安全水平。停止检测会停止后续问题，网页中已开始的生成可能仍需手动停止。登录配置目录和报告可能含敏感信息，请妥善保管。
